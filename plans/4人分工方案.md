## 三、4人分工详情

### 🧑‍💻 你（技术负责人 / 统筹）

**角色定位**：掌握全部代码细节，负责技术准确性把关和代码交付。

**负责交付物**：

1. **源代码整理（源代码 5分）**
   - 编写 `run_demo.sh`（一键起 App）和 `run_eval.sh`（一键评估）
   - 检查所有代码注释完整性，补充关键函数 docstring
   - 确认 `requirements.txt` 准确（V2 + App 两份）
   - 清理冗余文件（`rebuttal/__MACOSX`、`*.tar.gz`、空目录）
   - 验证可复现： fresh clone → install → run_demo 能跑通

2. **技术报告 · 技术章节（科学严谨性 30分 + 融合 10分）**
   - 撰写"系统架构"章节（含架构图，描述四模态→编码→Cross-Attention→分类）
   - 撰写"方法"章节（MediaPipe Tasks API、特征提取流程、融合网络结构、公式）
   - 撰写"实验"章节（数据集、训练配置、评估结果、消融实验表、混淆矩阵图）
   - 撰写"消融分析"章节（四模态贡献排名、与迭代2对比、讨论）
   - **关键**：把 [迭代3报告](../smart_elderly_care_v2/迭代3_视频模态真实化报告.md:1) 的内容扩写成正式学术报告章节

3. **统筹整合**
   - 汇总组员A/B/C的内容到完整报告
   - 确保技术描述准确（架构图、参数量、指标数字一致）
   - 最终交付物清单核对

**工作量估算**：2-2.5天

**角色定位**：负责报告的学术规范性和创新性论述，这是分值最高（20+30+20=70分关联）的部分。

**负责交付物**：

1. **文献综述与定位（新鲜感与意义 20分）⭐重点**
   - 检索并阅读 8-12 篇相关文献（多模态融合、老年人监护、跌倒检测、跨模态注意力）
   - 撰写"引言/研究动机"章节（老龄化背景、单模态局限、多模态融合必要性）
   - 撰写"背景与相关工作"章节（附引用，分析现有方法的假设/优势/局限）
   - **关键**：明确阐述本工作的创新点——"四模态真实数据融合 + Cross-Attention + 可解释性 + 缺失数据处理"，并说明与现有工作的差异
   - 推荐：引用 Attention Is All You Need、ViLBERT/ALBEF（跨模态注意力）、MediaPipe、ESC-50、老年人跌倒检测综述

2. **报告格式与结构（格式要求 20分）**
   - 统筹报告整体结构（按评分标准要求）：
     - 引言/研究动机

     - 结论与局限性

   - 控制字数（不大幅超限）

3. **结论与局限性章节**
