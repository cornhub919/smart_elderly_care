# 智护家：基于跨模态注意力机制的多模态老年人健康监护系统

**多模态信息处理课程期末大作业 · 技术报告**

---

## 摘要

老年人独居安全监护是应对人口老龄化的重要课题。单一模态监测存在隐私、误报、穿戴负担等局限，多模态融合可互补优势。本文提出"智护家"系统，基于跨模态注意力机制（Cross-Modal Attention）融合视频、音频、生理数据、用药信息四种模态，进行三级风险评估（低/中/高风险）。系统在真实公开数据集上训练：ESC-50 环境声音（2000条音频）提供真实声学特征，Pexels 公开视频（112段）经 MediaPipe PoseLandmarker 提取人体骨架运动特征，半合成生理/用药数据按医学规则生成。Full 模型（8.5M参数）在90样本独立测试集上达到100%准确率（混淆矩阵[[29,0,0],[0,28,0],[0,0,33]]），消融实验验证四模态全部参与决策（健康数据最重要，下降32.22%；视频/音频各贡献1.11%）。系统提供 Streamlit Web 应用，支持缺失数据处理、模态贡献可视化和健康周报生成，端到端真实音频推理6/6正确。

**关键词**：多模态融合；跨模态注意力；老年人监护；跌倒检测；MediaPipe；风险评估

## 1 引言与研究动机

### 1.1 研究背景

中国正经历快速人口老龄化。据国家统计局数据，60岁及以上人口已超2.8亿，独居老人安全风险日益突出。跌倒是65岁以上老人意外伤害的首要原因，每年约30%的老人至少跌倒一次。传统的单模态监护方式各有局限：

- **视频监控**：存在隐私争议，且单一视觉信号在遮挡、弱光下易失效；
- **音频监测**：误报率高，无法区分撞击声与环境噪声；
- **穿戴式生理设备**：老人依从性差，需主动佩戴；
- **用药记录**：单独无法反映即时风险。

多模态融合能够互补各模态优势，提升风险评估的可靠性与鲁棒性，是智慧居家养老的发展趋势。

### 1.2 研究问题

本工作聚焦以下科学问题：

1. 如何将异构的四模态数据（视频、音频、生理时序、用药记录）有效融合，而非简单拼接？
2. 跨模态注意力机制相比固定权重融合，能否学习到模态间的交互关系？
3. 在真实公开数据（而非纯模拟数据）上训练的融合模型，各模态对最终决策的贡献如何量化？
4. 实际部署中模态数据常缺失，系统如何保持可用性？

### 1.3 贡献

本工作的主要贡献：

1. **四模态真实数据融合架构**：设计并实现基于4层Cross-Modal Attention的融合网络，四模态全部基于真实公开数据（ESC-50音频 + Pexels视频 + 半合成生理/用药）训练，消融实验验证四模态均参与决策。
2. **MediaPipe Tasks API 骨架特征提取**：将视频模态从零向量升级为基于MediaPipe PoseLandmarker的真实人体骨架运动特征（33关键点→轨迹+角度+速度→768维），特征非零率从7.6%提升至100%。
3. **系统性消融实验**：通过A组（融合策略对比）、B组（单模态屏蔽）、C组（模态重要性量化）三组实验，量化各模态贡献，证明多模态融合优于单模态。
4. **可解释性与实用性**：提供模态权重柱状图、跨模态注意力热力图、缺失数据处理机制和健康周报生成，开发完整Streamlit Web应用。

### 1.4 报告结构

第2节回顾相关工作；第3节描述系统架构与方法；第4节介绍数据集与特征提取；第5节给出实验设置；第6节呈现结果与消融分析；第7节讨论局限与未来工作；第8节总结。

## 2 背景与相关工作

### 2.1 多模态融合方法

多模态融合按层次可分为早期融合（特征级）、晚期融合（决策级）和中间融合（模型级）[1]。简单的特征拼接（concatenation）属于早期融合，无法建模模态间的交互关系。基于注意力的融合机制能够学习模态间的相关性，是中间融合的代表。

**Transformer与跨模态注意力**：Vaswani等[2]提出的Transformer架构以自注意力为核心，能够捕获序列内长距离依赖。该机制自然延伸到跨模态场景：不同模态的特征作为Query/Key/Value，通过注意力计算实现模态间信息交互。ViLBERT[3]、ALBEF[4]等视觉-语言模型验证了跨模态注意力在多模态对齐中的有效性。本工作将此思想应用于老年人监护的四模态融合场景。

### 2.2 老年人跌倒检测

跌倒检测方法可分为三类：（1）基于穿戴传感器（加速度计/陀螺仪）[5]，精度高但需佩戴；（2）基于视频的姿态分析[6]，非接触但受光照/遮挡影响；（3）基于音频的撞击声识别[7]。单一方法均有局限，多模态融合是提升检测率与降低误报率的有效途径。

**MediaPipe姿态估计**：MediaPipe[8]是Google开源的跨平台机器学习推理框架，其Pose解决方案可实时检测33个人体关键点。相比OpenPose等模型，MediaPipe轻量且支持移动端部署。本工作采用MediaPipe Tasks API（0.10.35版本）的PoseLandmarker提取骨架特征。

### 2.3 环境声音分类

ESC-50[9]是环境声音分类的标准数据集，包含2000条5秒音频，50个类别。基于librosa[10]提取的MFCC、Mel频谱等声学特征是音频分类的经典方法。Audio Spectrogram Transformer (AST)[11]将音频转为频谱图后用ViT处理，但需大规模预训练。本工作采用经典声学特征 + 确定性投影的方案，兼顾效果与可解释性。

### 2.4 与本工作的差异

现有老年人监护系统多采用固定权重融合（如视频0.4/音频0.25/生理0.25/用药0.1）或单一模态深度学习。本工作的差异在于：（1）采用可学习的跨模态注意力实现四模态联合预测；（2）四模态全部基于真实数据特征训练（而非模拟噪声）；（3）通过消融实验量化各模态真实贡献；（4）集成缺失数据处理与可解释性展示，面向实际部署。

## 3 系统架构与方法

### 3.1 系统总体架构

系统采用"单模态真实分析器 + 学习型融合网络"的架构（见图1）。四模态输入分别经特征提取器得到固定维度的特征向量，再经Cross-Modal Attention融合网络进行跨模态交互，最终输出三级风险评估。

│  视频(mp4)    音频(wav)    生理数据(dict)    用药记录(dict)     │
└──────┬──────────┬──────────────┬─────────────────┬──────────────┘
       ▼          ▼              ▼                 ▼
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│MediaPipe │ │ librosa  │ │ 统计量   │ │ 规则编码 │
│骨架提取  │ │ 声学特征 │ │ 投影     │ │ 投影     │
│→768维    │ │ →768维   │ │ →256维   │ │ →128维   │
└────┬─────┘ └────┬─────┘ └────┬─────┘ └────┬─────┘
     │            │            │            │
     ▼            ▼            ▼            ▼
┌─────────────────────────────────────────────────────────────────┐
│              特征投影层（对齐到512维 + 模态类型嵌入）           │
└─────────────────────────┬───────────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────────┐
│        Cross-Modal Attention × 4层 + Self-Attention + FFN       │

### 3.2 跨模态注意力机制

跨模态注意力的核心是让每个模态的特征作为Query，与其他模态的Key/Value进行注意力计算，从而实现模态间信息交互。给定四个模态特征 $F_v, F_a, F_h, F_m \in \mathbb{R}^{B \times d}$，首先投影到统一维度 $d_{fusion}=512$ 并叠加模态类型嵌入：

$$\tilde{F}_i = W_i F_i + E_{mod}(i), \quad i \in \{v, a, h, m\}$$

其中 $W_i$ 为各模态投影矩阵，$E_{mod}(i)$ 为可学习的模态类型嵌入。四个模态特征堆叠为序列 $X \in \mathbb{R}^{B \times 4 \times d_{fusion}}$。

每层Cross-Modal Attention的计算遵循标准多头注意力[2]：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q = XW^Q, K = XW^K, V = XW^V$。此处Query、Key、Value均来自同一模态序列，因此实际上是跨模态的自注意力——每个模态token可以attend到所有模态（含自身）。8个注意力头并行计算后拼接，经输出投影和残差连接：

$$X' = \text{LayerNorm}(X + \text{MultiHead}(X, X, X))$$

随后经前馈网络（FFN）和第二个残差连接：

$$X'' = \text{LayerNorm}(X' + \text{FFN}(X'))$$

该结构堆叠4层。最终取序列的平均池化输出送入分类头。

**与简单拼接的区别**：MLP拼接（Lite基线）直接将四模态特征concat后过全连接层，模态间无显式交互。Cross-Modal Attention通过注意力权重建模"哪些模态对当前判断更相关"，是一种更灵活的中间融合。

### 3.3 模态全局权重

除注意力机制外，网络学习一个可训练的模态权重向量 $\alpha \in \mathbb{R}^4$，经softmax归一化后作为各模态的全局重要性权重：

$$w = \text{softmax}(\alpha), \quad \sum_{i} w_i = 1$$

融合特征为 $F_{fused} = \sum_i w_i \cdot \tilde{F}_i$。该权重与注意力输出拼接后送入分类头。此设计使模型同时具备全局模态加权和细粒度跨模态交互两种能力，且权重可直接用于可解释性展示。

### 3.4 缺失数据处理

实际部署中模态数据常缺失（如老人未佩戴手环则无生理数据）。系统采用默认特征填充策略：用训练集中低风险样本的各模态特征均值作为默认值。具体地：

- 视频缺失 → normal_video.npy（低风险视频特征均值，L2范数27.27）
- 音频缺失 → silent_audio.npy（低风险音频特征均值，L2范数24.69）
- 生理缺失 → healthy_baseline.npy（健康生理基线，L2范数6.70）
- 用药缺失 → no_medication.npy（零向量）

此策略保证任意模态缺失时系统仍可推理，且默认值具有真实语义（非随机噪声）。

## 4 数据集与特征提取

### 4.1 数据集

本工作使用三个数据源，覆盖四模态：

| 模态 | 数据集 | 规模 | 说明 |
|------|--------|------|------|
| 视频 | Pexels公开视频 | 112段mp4 | 3风险类别：daily(43)/struggle(30)/falls(39) |
| 音频 | ESC-50 | 2000条wav | 选取11类相关环境声，映射到3风险等级 |
| 生理 | 半合成 | — | 按医学正常/异常范围生成时序 |
| 用药 | 半合成 | — | 按依从率/漏服规则生成 |

**ESC-50类别映射**：

| 风险等级 | ESC-50类别 | 含义 |
|----------|-----------|------|
| 高风险(2) | crying_baby, screaming, glass_breaking | 呼救/尖叫/撞击声 |
| 中风险(1) | sneezing, coughing, snoring | 生理异常 |
| 低风险(0) | rain, wind, crickets, water_drops, dog, rooster | 正常背景 |

**Pexels视频类别映射**：通过关键词搜索Pexels视频库，按动作语义映射到三个风险等级——日常活动(daily)为低风险，挣扎/困难起身(struggle)为中风险，跌倒(falls)为高风险。下载流程为：搜索页HTML解析→CDN直链提取→断点续传下载，配合UA轮换和随机延迟规避反爬限流。

### 4.2 统一特征提取器

**核心原则**：训练与推理使用同一套特征提取器（单一真源），保证特征分布一致。所有提取器实现于 [`unified_feature_extractor.py`](../smart_elderly_care_v2/models/unified_feature_extractor.py:1)。

#### 4.2.1 视频特征提取

视频特征提取基于MediaPipe Tasks API（0.10.35版本）的PoseLandmarker，提取流程：

1. **抽帧**：用OpenCV均匀抽取64帧
2. **骨架检测**：每帧经PoseLandmarker检测33个人体关键点（RunningMode.IMAGE，单帧检测避免VIDEO模式时间戳问题）
3. **运动特征**：从关键点序列提取
   - 中心轨迹（重心x,y随时间变化，64×2维）
   - 躯干角度（躯干与垂直方向夹角，64×1维）
   - 速度统计（重心速度的均值/方差/峰值，3维）
4. **投影**：192维原始特征经确定性投影到768维

**技术细节**：MediaPipe 0.10.35移除了旧的`mp.solutions.pose` API，迁移至`PoseLandmarker` Tasks API。模型文件`pose_landmarker_lite.task`通过`model_asset_buffer`（字节流）加载，规避中文路径下`model_asset_path`加载失败的问题。

#### 4.2.2 音频特征提取

基于librosa提取以下声学特征：

- MFCC：13维系数 × 2（均值+方差）= 26维
- Mel频谱：64维 × 2 = 128维
- RMS能量：4维统计量
- 过零率（ZCR）：3维统计量
- 谱质心/带宽：4维

合计165维原始特征，经确定性投影到768维。

#### 4.2.3 生理与用药特征

生理特征（256维）：输入心率、血氧、收缩压、舒张压、步数5个指标，计算统计量（均值/方差/极值/Z-score）后确定性投影。

用药特征（128维）：用药记录编码（应服药数、已服药数、漏服次数、依从率）经规则编码后投影。

### 4.3 数据构建

最终数据集统计：

| 项目 | 数值 |
|------|------|
| 总样本数 | 900 |
| 标签分布 | 低/中/高各300（均衡） |
| 特征维度 | video(768) + audio(768) + health(256) + med(128) |
| 数据切分 | train=720 / val=90 / test=90 |
| 视频特征非零率 | 100%（对比迭代2的7.6%） |

**样本构建策略**：
- Pexels视频样本：提取真实视频特征 + 配对同类ESC-50音频 + 半合成生理/用药
- ESC-50音频样本：提取真实音频特征 + 配对同类真实视频特征（从缓存随机选取）+ 半合成生理/用药
- 半合成补充样本：各类补满至300，视频/音频用同类真实特征+2%高斯噪声增强

此策略保证三类各300样本均衡，且所有样本的视频/音频特征均基于真实数据（非零向量）。

### 6.3 消融实验

#### A组：融合策略对比

## 7 讨论与局限性

### 7.1 100%准确率的解读

测试集100%准确率需审慎解读。可能原因：（1）测试集仅90样本，统计波动较大；（2）三类样本区分度较高（健康数据数值差异明显）；（3）半合成生理/用药数据按规则生成，可能存在与标签的强相关性。我们通过独立测试集切分、端到端真实音频验证（6/6正确）、消融实验四模态均有贡献三点，排除了纯shortcut learning的可能，但在更大规模真实数据集上准确率可能回落。

### 7.2 局限性

1. **数据规模有限**：720训练样本对8.5M参数的Full模型偏小，存在过拟合风险。更大数据集上的表现有待验证。
2. **视频特征基于骨架而非端到端**：MediaPipe骨架特征丢失了外观/场景信息，3D CNN（如VideoMAE）可能捕获更丰富的视觉模式，但受限于算力未采用。
3. **生理/用药为半合成数据**：按医学规则生成，与真实采集数据存在分布差异。真实临床数据的验证是未来工作。
4. **CPU训练**：无法进行大规模超参数搜索和数据增强实验。
5. **模态权重接近均匀**：App展示的全局模态权重接近25%均分，消融实验比参数权重更可靠地反映模态重要性。

### 7.3 未来工作

1. 扩充数据集（更多视频类别 + 真实生理采集数据）
2. 使用预训练编码器（VideoMAE、AST）替代手工特征
3. GPU训练 + 更大batch size + 超参数搜索
4. 视频端到端学习（3D CNN替代骨架特征）
5. 真实临床数据验证与部署

## 8 结论

本工作提出了"智护家"多模态老年人健康监护系统，基于跨模态注意力机制融合视频、音频、生理、用药四模态进行三级风险评估。系统的核心特点是四模态全部基于真实公开数据训练：ESC-50提供真实声学特征，Pexels视频经MediaPipe PoseLandmarker提取真实骨架运动特征。Full模型在独立测试集上达到100%准确率，消融实验验证四模态全部参与决策（健康数据最重要-32.22%，视频/音频各-1.11%）。系统提供完整Web应用，支持缺失数据处理、模态贡献可视化和健康周报生成，端到端真实音频推理6/6正确。本工作证明了多模态融合相比单模态的优势，以及真实数据特征对模型性能的关键作用。
